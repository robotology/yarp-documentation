Detailed Description

stats_monitor: When this port monitor is attached to the sender side of a connection, it opens two additional output ports (one for forward data and one for backward data).

These ports provide statistics about the connection, such as bandwidth usage (in Bytes/s) and the number of writes per second. The names of the two ports are automatically generated according to the following pattern: /stats_monitor/" + m_source + m_destination + "/stats:o" data from source to destination /stats_monitor/" + m_destination + m_source + "/stats:o" data from destination back to source (for example in a rpc connection)
