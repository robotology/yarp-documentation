Detailed Description

This class is the parameters parser for class KokoroSpeechSynthesizer.

These are the used parameters:

Group name Parameter name Type Units Default Value Required Description Notes
- python_executable string - python3 0 Python interpreter containing the kokoro package. -
- worker_script string - - 0 Path to kokoro_worker.py. If omitted, the build or installed worker is used. -
- model_repository string - hexgrad/Kokoro-82M 0 Hugging Face model repository used by Kokoro. -
- torch_device string - - 0 PyTorch execution device, for example cpu or cuda. The empty value lets PyTorch/Kokoro choose automatically. -
- language string - en 0 Speech language: en, en-gb, es, fr, hi, it, ja, pt-br, zh, or a Kokoro language code. -
- voice string - auto 0 Kokoro voice name, for example af_heart or bf_emma. -
- speed double - 1 0 Speech speed in the range (0, 4]. -
- pitch double - 0 0 Stored for ISpeechSynthesizer compatibility. Kokoro currently does not apply pitch. -

The device can be launched by yarpdev using one of the following examples (with and without all optional parameters):

yarpdev --device kokoroSpeechSynthesizer --python_executable python3 --worker_script <optional_value> --model_repository hexgrad/Kokoro-82M --torch_device <optional_value> --language en --voice auto --speed 1 --pitch 0
yarpdev --device kokoroSpeechSynthesizer
