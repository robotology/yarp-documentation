Detailed Description

YARP speech synthesizer backed by the Kokoro Python package.

The plugin keeps a small Python worker alive and communicates with it through stdin/stdout. This avoids embedding Python in the YARP process while still keeping the Kokoro model loaded between synthesis requests.
