Returns a human readable representation of the vector, with formatted numbers.

Parameters
precisionnumber of digits after the decimal point. A negative value selects the printf default (6). Values greater than 100 are clamped.
widthminimum field width of each element. If negative, elements are separated by a tab, otherwise they are right-aligned in a field of the given width and separated by a space. Values greater than 100 are clamped.
Returns
the formatted string (empty if the vector is empty).
