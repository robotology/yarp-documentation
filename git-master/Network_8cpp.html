const Contact &  dest,
const ContactStyle &  style,
int  mode,
bool  reversed

static

Connect, disconnect, or check the connection between two ports, by sending administrative commands to the port src, which is the one in charge of the connection (it is called by metaConnect()).

The steps are:

  • for persistent connections, the request is forwarded to the name server and the ports are not contacted at all;
  • otherwise src is asked (getConnectionInfoOut/getConnectionInfoIn, see PortCoreMsgs.thrift) about the current connection with dest. If src does not respond, it is reported to the name server as dead (noteDud());
  • in YARP_ENACT_EXISTS mode, the result depends only on the existence of the connection and on its carrier (which must match style.carrier);
  • an existing connectionless connection is explicitly disconnected also from the other side, since the other side would not notice it otherwise;
  • finally, src is asked to add (addConnection) or to remove (delConnection) the connection.
Parameters
srcthe port which is asked to make/break/check the connection
destthe port at the other end of the connection
stylethe options of the connection (carrier, timeout, quiet, ...)
modeone of YARP_ENACT_CONNECT, YARP_ENACT_DISCONNECT, YARP_ENACT_EXISTS
reversedfalse if src is the sender of the data (push connection), true if src is the receiver of the data (pull connection)
Returns
0 on success, 1 on failure

◆ noteDud()

static int noteDud ( const Contact &  src)
static

Notify the name server that a port did not respond (i.e.

it is probably dead), by announcing it with activity 0. The name server can use this information to mark the port as non-live and to clean up its registration.

If a local name store is available (query bypass), it is notified directly, otherwise an "announce <port> 0" message is sent to the name server.

Parameters
srcthe port which did not respond
Returns
the result of the announcement (it is not used by the callers)
