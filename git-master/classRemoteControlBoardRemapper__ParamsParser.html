Detailed Description

This class is the parameters parser for class RemoteControlBoardRemapper.

These are the used parameters:

Group name Parameter name Type Units Default Value Required Description Notes
- remoteControlBoards vector<string> - - 1 Ordered list of the axes that are part of the remapped device. -
- axesNames vector<string> - - 1 List of remote prefix used by the remote controlboards The element of this list are then passed as "remote" parameter to the RemoteControlBoard device.
- localPortPrefix string - - 1 All ports opened by this device will start with this prefix -
- verbose bool - false 0 print additional output if enabled -

The device can be launched by yarpdev using one of the following examples (with and without all optional parameters):

yarpdev --device remotecontrolboardremapper --remoteControlBoards <mandatory_value> --axesNames <mandatory_value> --localPortPrefix <mandatory_value> --verbose false
yarpdev --device remotecontrolboardremapper --remoteControlBoards <mandatory_value> --axesNames <mandatory_value> --localPortPrefix <mandatory_value>
