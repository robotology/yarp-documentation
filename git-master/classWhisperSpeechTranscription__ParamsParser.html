Detailed Description

This class is the parameters parser for class WhisperSpeechTranscription.

These are the used parameters:

Group name Parameter name Type Units Default Value Required Description Notes
- model_context string - - 0 context of Whisper model Here are additional notes
- model_name string - - 1 name of Whisper model Here are additional notes
- language string - auto 0 Language (??? TBC) Here are additional notes
- remove_symbols int - 1 0 If symbols from output text, (i.e. ...[bla bla]...) are removed Here are additional notes

The device can be launched by yarpdev using one of the following examples (with and without all optional parameters):

yarpdev --device yarp_whisperSpeechTranscription --model_context <optional_value> --model_name <mandatory_value> --language auto --remove_symbols 1
yarpdev --device yarp_whisperSpeechTranscription --model_name <mandatory_value>
