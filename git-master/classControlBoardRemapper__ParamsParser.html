Detailed Description

This class is the parameters parser for class ControlBoardRemapper.

These are the used parameters:

Group name Parameter name Type Units Default Value Required Description Notes
- axesNames vector<string> - - 0 Ordered list of the axes that are part of the remapped device. e.g.(/joint0 /joint1) -
- networkNames vector<string> - - 0 List of the robot parts to be used in remapped device. e.g.(/partA /partB) Deprecated. Requires additional params (here not specified). Cannot be used together with axesNames
- verbose bool - false 0 print additional output if enabled -

The device can be launched by yarpdev using one of the following examples (with and without all optional parameters):

yarpdev --device controlboardremapper --axesNames <optional_value> --networkNames <optional_value> --verbose false
yarpdev --device controlboardremapper
