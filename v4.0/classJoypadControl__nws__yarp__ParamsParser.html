Detailed Description

This class is the parameters parser for class JoypadControl_nws_yarp.

These are the used parameters:

Group name Parameter name Type Units Default Value Required Description Notes
- period double s 0.01 0 Refresh period (in s) of the broadcasted values through yarp ports -
- name string - /robotName/joypad 1 Prefix name of the ports opened by the JoypadControlServer -
- profile bool - false 0 print the joypad data for debugging purpose -
- publish_on_event bool - false 0 if true, events, are published when the status changes (on event). Otherwise they are published at the frequency specified through the period parameter -

The device can be launched by yarpdev using one of the following examples (with and without all optional parameters):

yarpdev --device JoypadControl_nws_yarp --period 0.01 --name /robotName/joypad --profile false --publish_on_event false
yarpdev --device JoypadControl_nws_yarp --name /robotName/joypad
