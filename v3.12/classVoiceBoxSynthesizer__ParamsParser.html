Detailed Description

This class is the parameters parser for class VoiceBoxSynthesizer.

These are the used parameters:

Group name Parameter name Type Units Default Value Required Description Notes
- base_ip string - localhost 0 The ip address of the voiceBox server -
- base_port string - 17493 0 The port for the voicebox address -
- voice string - - 1 The name of the voice profile To check the available profiles, either check in the VoiceBox app or use the following command: curl http://server_ip_addr:server_port/profiles

The device can be launched by yarpdev using one of the following examples (with and without all optional parameters):

yarpdev --device voiceBoxSynthesizer --base_ip localhost --base_port 17493 --voice <mandatory_value>
yarpdev --device voiceBoxSynthesizer --voice <mandatory_value>
